# Changelog

## 0.1.0 development prerelease

Initial Godot 4.7.2 source project, playable Goku/Vegeta geometric placeholders, 20 functional form selections, shared signature attack systems, melee, flight, guarding, ki, AI, interactive beam clashes, seven procedural arena layouts, six mode selections, touch/keyboard controls, persistent settings and synthesized audio.

Added Android ARM64 export settings, a signed development-distribution APK, checksum/ABI/signature/alignment verification tools, a logic test suite and a GitHub Actions development build workflow.

This is not the finished master-prompt game. Actual Android device tests, authored character models and skeletal animations, cinematic attacks, final VFX/audio, performance targets and several deeper mechanics remain unfinished. See DEVELOPMENT.md for the full status and BUILDING.md for installation and signing details.
